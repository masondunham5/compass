    Settings

    Garmin Personal API

    Checking Garmin status…

    Copy .env.example to .env on this computer, paste your key after GARMIN_PERSONAL_API_KEY=, add its expiration date, then sync. The key never appears in this page, the database, or GitHub.

    Bodyweight

    Used for pull-ups and dips, so their estimated 1RM counts you plus any added weight. A weight from a daily check-in takes priority.

    Calendars

    Read-only: Compass never changes these calendars. Events are treated as fixed when planning workouts. The link is stored only on this computer and never shown again in full.

    Personal Outlook

    Puts your accepted plan and your Compass events into your personal Outlook Calendar (tagged “Compass”), and reads your other Outlook events as busy time. Compass only changes your own Outlook events when you ask it to.

    AI assistant

    Talk or type to change your schedule (the chat button on every screen). Built-in commands like “swap chest and back” work without a key; for everything else, add a free Groq API key from console.groq.com. xAI and Gemini keys work too.

    Reminders

    Notifications for your check-in, workout and Garmin's bedtime window. They fire while Compass is open or installed in this browser; true background reminders come with phone access.

    Private by design

    Compass runs against its local database. Garmin data stays on this server; no Garmin password is stored.
